Bare-metal LED blink and button driver for STM32H747I-DISCO, no HAL or CMSIS

What it contains: register-level GPIO driver, SysTick delay, startup file, linker script
Hardware: STM32H747I-DISCO, ST-Link USB cable
Build: the exact make command you use
Flash: the OpenOCD or STM32CubeProgrammer command you use
Notes: the LEDs are active-low, the clock is 64 MHz HSI, the code runs on the M7 core
